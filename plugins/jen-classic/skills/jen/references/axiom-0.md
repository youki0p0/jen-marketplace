# AXIOM-0 — Claude のみで完結する

**これは Jen の他のすべての原則の上位に置く。** 性能・論文の裏付け・流行は、
この制約を覆す理由にならない。設計判断が AXIOM-0 と衝突したら、設計判断を捨てる。

## 制約がかかるのは「知能」であって「道具」ではない

### ✗ 禁じる — 知能が Claude の外へ出る

1. **Claude 以外のモデルに判断させること。**
   他社 LLM、ローカル LLM、学習済み分類器、埋め込みモデルに判定を委ねない。
2. **学習・微調整を要する部品。**
   LoRA、報酬モデル、preference dataset、進化探索。そもそも Claude 内で作れない。

### ✓ 許す — Claude 内から実行できる道具

3. **MCP サーバ。** ブラウザ自動化、テスト実行、DB、git など。
   **自作より既存を使う方を優先する。**いちから作るのは建設的でない。
4. **外部コマンド・ライブラリ。** Claude Code の Bash から叩けるもの。
5. Claude Code のプラグイン面（`agents/` `skills/` `commands/` `hooks/` `templates/`）。

## 運用上の原則（公理ではなく設計判断。区別する）

6. **特定の MCP サーバや外部コマンドを「必須」にしない。**
   あれば使い、無ければ縮退する。理由は公理ではなく Jen の既存の約束
   ——「以上。リポジトリに何も展開しません」。
   **インストールが工事になった時点で Jen の良さが消える。**
   → **hooks 本体は標準ライブラリのみで書く**（必ず動く下限）。
   道具はその上の任意層に置く。
7. 書き込み先は作業リポジトリ内の `.jen/` のみ。外部へ送信しない。

## 判定の実例（2026-10 の調査で採否を決めたもの）

| 機構 | 判定 | 理由 |
|---|---|---|
| HALT の停止の決め方（項目ごとに証拠がそろったか・状態が下がらない・ALL_MATCH） | **採る** | 考え方だけ移す。集計は Python |
| HALT の検証器 Vθ（Qwen2.5-3B + LoRA） | **✗** | 他社モデルに判断させる＋要学習 |
| ブラウザ自動化での検収（Puppeteer / Playwright MCP） | **✓** | Claude 内から実行できる。ただし必須化しない |
| Sakana Fugu（オーケストレーションをモデルに内蔵） | **✗** | Claude でないモデル |
| Sakana Trinity / Conductor（学習した指揮者） | **✗** | 要学習 |
| Sakana DGM / MASS（再帰的自己改善） | **✗** | モデル改変 |
| Meta-Harness / AutoHarness（ハーネス自動探索） | **✗** | 要学習 |
| モデル別の検証頻度（Jain / Anthropic） | **採る** | `model:` エイリアスが分岐キーになる。Classic の最上位は `opus` |

Sakana 系が全滅する点について: Jen v1 は Sakana Fugu 型のルーティング思想から
出発したが、2026年の Fugu は「オーケストレーションをモデルの中に入れる」方向へ行った。
それは AXIOM-0 と**両立しない**。思想の参照先としては残るが、実装は採らない。

## なぜこの制約が設計を良くするか（偶然ではない）

Jain 2026-10 の結論は「ハーネス最大の危険は**オーバーヘッド**」である
（フロンティアで約16倍のトークン、合否は不変）。
AXIOM-0 は**薄いハーネスを強制する**。重い外部機構を積めないので、
最強の反証が警告したコストが構造的に抑えられる。

さらに「ハーネスの各要素はモデルができないことの仮定」（Anthropic / P9）だとすれば、
部品はいつか期限が切れて捨てることになる。**AXIOM-0 は賭けを小さく張るための制約**
として機能する。捨てる量が最小で済む。

## 監査

skillmap 整合性チェック（`behavior-audit.md`）の「既知のドリフト源」に
**AXIOM-0 違反**を入れてある。scout が次を機械的に確認する:

- `hooks/` に標準ライブラリ以外の import が入っていないか
- `pip install` / 外部コマンドを**必須**として要求する記述が増えていないか
- 特定の MCP サーバ無しでは動かない記述になっていないか
- Claude 以外のモデル名が実行対象として書かれていないか

「お願い」ではなく機械的に見つける対象にしてある。
今回の調査の核心（証拠は偽造できない形にする）を、Jen 自身の思想の保全にも当てている。
