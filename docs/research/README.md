# v4 設計の調査記録（2026-10-22）

Jen v4 の設計を決めるために行った文献調査の**生の記録**。
清書した結論は `docs/jen-v4-design.pdf` と各 `references/*.md` にあるが、
ここには**検討して捨てた経緯**が残っている。

## なぜ残すか

清書だけ残すと、後から同じ案を再検討したときに**同じ結論に戻れない**。
実際に今回、Kastner 2007（capture-mark-recapture による停止則）は
**要約を読んだ段階では採用するつもりだった**。原文を読んで初めて
「閾値が未確立」「著者自身のデータで一度も発火していない」と分かり不採用にした。
この経緯が消えると、未検証の停止則をハーネスの中核に入れる事故が起きうる。

## 原文（`sources/`）は入れていない

調査では第三者の論文・記事30本（うちPDF 12本）を取得したが、
**公開リポジトリに置くと再配布になる**ため含めない。
各ファイルの URL・書誌情報・引用した行番号は上記の記録に残してあるので、
必要なら各自で取得できる。

調査には `MaryCache/imozuru`（芋づる式に原文へたどる Claude Code スキル）を使い、
英語・日本語の2経路を独立に走らせた。
